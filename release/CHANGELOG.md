# 1.0.0

First release.

- Four Mechanical Mixer upgrade kits: Brass (16x), Precision (32x), Sturdy (48x) and Blazing (64x) recipes per mixing cycle.
- Kits install with right-click and come out with sneak + empty-hand right-click. They drop when the mixer is broken and stay with a mixer moved by a contraption.
- Engineer's Goggles show the installed tier.
- Ponder walkthrough for the kits and the Mechanical Mixer.
- Configurable batch size per tier.
